DualSense Reimagined — Full DualSense Integration for Gothic 1 Remake (PC)
Author: Marvin2242

INSTALL
1. Extract the archive into the game folder (where G1R-Win64-Shipping.exe is).
2. Start the game with GothicDualSense\GothicDualSense.exe (make a desktop shortcut if you like).
That's it. The effects bridge runs in the background and closes with the game.

CONTROLLER
- USB cable: full HD haptics. Set the "DualSense Wireless Controller" volume in Windows sound settings to 100 %.
- Bluetooth: everything works except the microphone whistle; HD haptics are weaker.
- Close DSX and similar tools.
- Steam: disable Steam Input for the game (Properties → Controller → "Disable Steam Input"),
  otherwise Steam may override the lightbar and turn the touchpad into a mouse.

UNINSTALL
Delete the folders GothicDualSense and G1R\Mods\G1R_DualSenseBridge. No game files are changed.

TROUBLESHOOTING
Logs: GothicDualSense\logs (launcher.log and the latest play_*.log) — attach them to a bug report.
Tested on game versions 1.1a and 1.1b (GOG).
